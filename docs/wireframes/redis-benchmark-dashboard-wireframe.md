# Redis 성능 비교 대시보드 와이어프레임

이 low-fi 와이어프레임은 Figma로 바로 가져가서 스타일링할 수 있게 만들었다.

파일:
- `docs/wireframes/redis-benchmark-dashboard-wireframe.svg`

Figma 사용 방법:
1. Figma 드래프트 파일을 연다.
2. SVG 파일을 캔버스로 드래그한다.
3. 한두 번 ungroup 해서 섹션별로 편집 가능하게 만든다.
4. 팀 스타일에 맞는 타이포그래피와 색상 시스템으로 입힌다.

프레임 구성 의도:
- 상단: 공통 헤더와 현재 데모 시나리오 요약
- 상단 중간: `DB 전용` / `Redis + DB` 서비스 미리보기
- 중단: 핵심 성능 지표, 지연 시간 차트, Redis 손익분기 적중률 표시
- 하단 왼쪽: 실험 제어 패널
- 하단 오른쪽: 실행 로그 / 이벤트 콘솔

추천 Figma 섹션 이름:
- `헤더`
- `시나리오 요약`
- `서비스 미리보기 / DB 전용`
- `서비스 미리보기 / Redis + DB`
- `실시간 비교`
- `실험 제어`
- `실행 로그`

추천 컴포넌트 세트:
- 검색 바
- 서비스 카드
- 성능 지표 타일
- 상태 칩
- 차트 컨테이너
- 제어 입력 필드
- 기본 액션 버튼
- 보조 액션 버튼
- 이벤트 로그 행

추천 디자인 동작:
- 상단 미리보기는 실제 사용자가 보는 서비스 화면처럼 보여야 한다.
- 중단 영역은 성능 계측 패널처럼 동작해야 한다.
- 하단은 실험자가 파라미터를 조절하는 운영 콘솔처럼 보여야 한다.
- 비교 패널 안에는 `몇 % 적중률부터 Redis + DB가 더 빠른지`를 바로 읽을 수 있는 손익분기 카드가 있어야 한다.

추천 인터랙션 흐름:
1. 사용자가 시나리오와 실행 옵션을 선택한다.
2. `벤치마크 실행` 버튼을 누르면 두 서비스 미리보기가 동시에 시작된다.
3. 상단 패널에서 로딩 상태와 완료 속도 차이가 보인다.
4. 중단 KPI와 차트가 실시간으로 갱신된다.
5. 하단 로그에는 Redis flush, 데이터 적재, 실행 완료 같은 이벤트가 쌓인다.

데모 효과가 큰 시나리오:
- 상세 페이지 반복 조회
- 검색 자동완성 집중 부하
- 인기글 랭킹 갱신
- 콜드 캐시와 웜 캐시를 섞은 혼합 워크로드

Redis 적중률 표현 가이드:
- KPI 영역에 `손익분기 적중률` 타일을 둔다.
- 예시 문구: `35% 이상이면 Redis + DB가 더 빠름`
- 차트 하단 보조 설명에는 `35% 이상부터 평균 지연이 역전되고, 60% 이상에서 차이가 크게 벌어짐` 같은 해석 문장을 둔다.
- 실제 구현에서는 시나리오별로 손익분기 적중률이 달라질 수 있으므로 숫자는 동적으로 바뀌는 구조가 좋다.

속도 향상 요약(`7.6x`) 표현 가이드:
- `7.6x`는 `DB 전용 평균 지연시간 / Redis + DB 평균 지연시간`을 뜻한다.
- 예시: `182ms ÷ 24ms ≈ 7.6`
- 사용자 문구는 `Redis + DB가 7.6배 빠름` 또는 `86% 더 빠름` 둘 다 같이 보여주는 게 이해가 쉽다.
- 와이어프레임에서는 속도 향상 카드 안에 숫자와 함께 계산식 보조 문구를 같이 둔다.

손익분기 적중률 계산 로직 아이디어:
1. 같은 시나리오를 적중률 구간별로 나눠 여러 번 실행한다.
2. 예: `0%, 10%, 20%, 30%, 35%, 40%, 50%, 60%, 80%, 100%`
3. 각 구간에서 `DB 전용 평균 지연`과 `Redis + DB 평균 지연`을 기록한다.
4. `Redis + DB 평균 지연 <= DB 전용 평균 지연`이 처음 성립하는 적중률을 손익분기점으로 잡는다.
5. 그 값을 KPI 카드의 `손익분기 적중률`로 보여준다.

백엔드 계산 흐름 예시:
- 입력:
  - scenario
  - iteration count
  - concurrency
  - hit rate buckets
- 처리:
  - DB 전용 모드 벤치마크 수행
  - Redis + DB 모드에서 적중률을 강제로 맞춘 샘플 요청 수행
  - 구간별 평균/중앙값/p95 기록
- 출력:
  - `db_avg_ms`
  - `redis_avg_ms`
  - `speedup_ratio`
  - `improvement_percent`
  - `break_even_hit_rate`
  - `hit_rate_curve[]`

차트 추가 가이드:
- `시간대별 지연 변화` 차트 옆에 `적중률 대비 평균 지연` 차트를 둔다.
- X축은 적중률(%), Y축은 평균 지연(ms)이다.
- DB 전용은 거의 평평한 기준선처럼 보이고, Redis + DB는 적중률이 오를수록 내려가는 선으로 표현한다.
- 두 선이 처음 교차하는 지점에 `손익분기점` 라벨을 붙인다.
